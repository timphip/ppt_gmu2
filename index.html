Insight

Why Auto3 works

  1. 1The backdoor depends on exact quantized values, and the attack keeps them in a constrained space.
  2. 2Auto3 adds a small perturbation that keeps each row’s mean and variance, so performance stays.
  3. 3The same perturbation flips enough of these values to disrupt the backdoor.

INT8

Gaps between quantized values are small → many weights flip (37–39%) → code security 86–99.

4-bit

Gaps are larger → fewer weights flip (about 5%) → the improvement is more limited for StarCoder (17–23 → about 65). Phi-2 reaches 94–98.
